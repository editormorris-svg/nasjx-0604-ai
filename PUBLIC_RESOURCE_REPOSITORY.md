# NASJX Public Resource Repository

This public repository is the distribution layer for approved NAS Jiaxing English & AI Learning Hub releases.

Canonical source and governance remain in the private `editormorris-svg/GPT-ZYK` repository. Only files that have passed the applicable release and QA gate and appear in `PUBLIC_RESOURCE_ALLOWLIST.txt` are copied here.

Public portal: `https://nasjx.0604.ai`

## Public release boundary

Public files are limited to:

- student-ready coursebooks and student practice editions;
- deliberately public professional-development handouts and packs.

The public repository must not contain answer books, teacher keys, private teacher materials, editable/internal masters, unreleased assessments, copyrighted source material, credentials or internal strategy. Teacher-only material belongs in private governed storage and may later be served only through authenticated authorisation.

## Current release layout

- `resources/01 AI Club/`
- `resources/02 Grammar Practice G6-G12/` — student editions only
- `resources/03 Stage 7 Grammar/` — student edition only
- `resources/04 Teacher PD/`

Teacher PD v0.1 contains the current NAS Jiaxing **Practical AI for Teachers** public release. Legacy 0604.ai workshop binaries are not part of the current release.

Future lanes remain subject to their own publication gates: Literature teaching packs, additional Literature Games, Progression Tests and authenticated local-AI services.

Google Drive remains the release source / backup archive. The automated sync copies only the exact paths in `PUBLIC_RESOURCE_ALLOWLIST.txt`; it does not mirror every file that happens to exist in a release folder.

Last release-boundary update: 2026-09-01 — teacher keys, answer books and answer-bearing collection ZIPs withdrawn from public distribution.
